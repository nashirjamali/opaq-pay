# Opaq

Private payments on Solana: accept stablecoins from any chain without exposing your wallet.

- **Opaq Link** – private payment links for freelancers and creators
- **Opaq Checkout** – checkout widget for online stores
- **Opaq SDK / API** – private payments for platforms

> Work in progress. "Opaq" is a working name.
